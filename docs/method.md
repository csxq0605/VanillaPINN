# 方法说明

[← 返回 README](../README_CN.md) · [消融实验](ablations.md) · [文献调研](literature_survey_cn.md)

## 1. 问题

二维定常无粘可压缩 Euler 方程，超声速来流过楔面，产生从楔尖出发的附体斜激波（γ = 1.4）。最终目标是斜爆轰波（ODW），斜激波是它的前导结构。

- 计算域：楔长 L = 1，x ∈ [−0.25, 1]，y ∈ [0, y1]。楔尖在原点，楔面 y = x·tanθ（x > 0）。
- 无量纲：ρ∞ = p∞ = 1，u∞ = √γ·Ma。
- 参考解：
  - 斜激波理论精确解（`physics.oblique_shock`），用于所有参数化评估。
  - OpenFOAM `rhoCentralFoam`：10°、15°，Ma 5，缓存在 `wedge_pinn/data/*.npz`。
- 网络输出 (u, v, ln ρ, ln p)，用 exp 保证 ρ、p 为正。
- 一、二阶导数用 Taylor 模式前向传播一次算出（`model.forward_derivs`），比反复调用 autograd 快约 5 倍。

## 2. 两条路线

| | 单工况：捕捉 → 识别 → 装配 | 参数化：只用方程的激波捕捉 |
|---|---|---|
| 输入 | (x, y) | (x, y, Ma, θ) |
| 激波先验 | 第 3 步用 RH 条件和"激波是一条曲线" | **完全不用**：无 RH、无激波位置、不按激波加点 |
| 代码 | `capture_lv.py` → `refine.py` → `shockfit.py` | `param_pinn.py` |
| 结果 | 激波角误差 ≤ 0.007°，对精确解扰动 L2 ≤ 7e-4 | 16 个工况激波角平均 0.09°、最大 0.17°，ρ 3.0%、p 4.4% |

### 2.1 单工况流程

1. **激波捕捉 PINN**（`capture_lv.py`）
   - 配方：逐点可学习粘性 ν = s²，加 0.01·mean(ν) 的 L1 型惩罚。
   - 残差除以压缩区权重 d（不 detach）。
   - 壁面附近压低粘性（`--nu_wall`）。
   - 残差自适应加点（RAD），第 400 步后冻结。
   - 小方框积分守恒损失（`--w_weak`）。
   - 先 Adam 预热，再用 L-BFGS。
   - 10° 算例上，对 CFD 的全场相对 L2 为 ρ 1.0–1.3%、p 1.8–2.5%（3 个随机种子）。
2. **自动识别激波**（`refine.py: detect_shocks`）
   - 在 500×500 网格上算压缩量 C = max(0, −∇·u)。
   - 沿密度梯度方向做非极大值抑制，提取脊线；再做连通域分组和稳健直线拟合。
   - 判断激波是否附体于楔尖，输出激波的拓扑和角度。
3. **激波装配精修**（`shockfit.py`）
   - 激波是一条可学习曲线 y_s(x) = x·tan(β0 + g(x))。
   - 上、下游各用一个网络，在各自区域内满足光滑 Euler 方程；激波线上施加 RH 条件 [F·n] = 0。
   - 初始角从 14° 到 45° 都能收敛到正确激波角。

### 2.2 参数化、只用方程的激波捕捉（主要工作）

规则：只能用方程本身，以及边界条件、配点策略、人工粘性、残差降权、积分形式这类"方程的离散方式"。**每一项都要有理论依据**，且对所有 (Ma, θ) 一视同仁。最终方程为

  ∇·F(U) − ν(Ma)·ΔU = 0，  ν(Ma) = ν0 · u∞(Ma) / u∞(5)

ν 随 u∞ 缩放，相当于固定雷诺数，激波厚度只随 ν0 变化。各组成部分及其理论依据：

| 组成 | 参数 | 理论依据 |
|---|---|---|
| **逐步减小的常数人工粘性** | `--nu_mode const --nu`：4e-3 → … → 7e-4 | 粘性消失法（vanishing viscosity）。ν → 0 时，粘性解收敛到满足熵条件的弱解，RH 条件自动成立，不需要手工加入。粘性必须由外部给定：可学习粘性会被网络自己放大，因为强形式残差在激波内 ∝ 1/厚度。 |
| **参数调制首层** | `--arch hyper` | 第一层的 W、b 由 (Ma, θ) 的小网络生成，初值为零。激波面 y = x·tanβ(Ma, θ) 在 (x, y, Ma, θ) 空间里不是平面，普通 MLP 第一层的超平面跟不上它随参数转动。依据是 shift-DeepONet / 非线性重构（Lanthaler et al. 2022）和 HyperPINN。 |
| **各守恒律按自身来流通量归一** | `--eq_scale own` | 质量、动量、能量方程的量级相差约 440 倍。不归一时，能量方程主导损失，质量方程几乎不起作用。 |
| **楔尖残差降权** | `--tip_delta 0.01` | 楔尖是几何奇点：速度方向在这一点间断，对称线条件和壁面条件矛盾。残差乘以 r²/(r²+δ²)，是 Kondratiev 型角点加权范数，只用到几何。 |
| **壁面增广拉格朗日** | `--alm true` | 纯罚函数法下，损失最小值落在"牺牲一点壁面条件、让激波弱一点"的解上，因为残差 ∝ 跳跃²/厚度。乘子项吸收这部分偏差（PECANN，Basir & Senocak 2022）。 |
| **强 Wolfe 线搜索 L-BFGS + 停滞重采样** | `--line_search strong_wolfe`，`--stall_resample` | 固定步长的 L-BFGS 在激波这种刚性问题上很慢。线搜索收敛后若损失完全不变，就重新取点并重启优化器。 |
| **四维残差自适应加点（RAD）** | `--n_rad 27500 --rad_pool 140000` | 在 (x, y, Ma, θ) 里按残差采样，点自然落到激波面上，不用任何激波位置信息。激波变薄后，点数决定能否分辨它。 |
| **训练参数域比使用范围宽** | `--ma_min 2.5 --th_max 21 --y1 1.05` | 参数域的边和角上，网络缺少一侧的"邻居"，误差从角上向内平滑衰减，大约每 0.15 Ma 减半。训练域放宽后，使用范围离边界更远。 |
| **保持函数不变的加宽** | `widen_model.py` | 新神经元的输出权重置零，加宽前后 q 和各阶导数完全一致（< 4e-7），可以直接从已有解出发增大网络容量。 |

训练从粗到细，每段都从上一段的解出发（`--init_from`），完整链条见 [`wedge_pinn/scripts/train_param.sh`](../wedge_pinn/scripts/train_param.sh)，每一步的效果见 [消融实验](ablations.md)。

## 3. 指标

- **激波角 β**：压力 50% 位置和楔尖连线的角度，取 x = 0.5 / 0.75 / 0.95 三个测站的平均。`diag_param/beta_precise.py` 另外给出直线拟合方向，以及由激波后压力反推的激波角。
- **相对 L2**：全场 ‖q − q_exact‖ / ‖q_exact‖，参数化模型的评估窗口为 y ≤ 0.9。
- **扰动相对 L2**：‖q − q_ref‖ / ‖q_ref − q∞‖，用于单工况和 CFD 的对比，不会被大片均匀来流"稀释"。
- **激波厚度下限**：把精确解按 PINN 自己的激波厚度用 tanh 抹开后算出的 L2，即"位置完全正确、只是有厚度"时能达到的最好成绩（`diag_param/band_err.py`）。最终模型 p 的 L2 为 4.4%，其中 3.0 个百分点就是这个下限；离激波 ±0.03 以外，误差只有 0.2%。
