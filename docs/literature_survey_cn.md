# PINN 求解含激波 Euler 方程：文献调研与方法分类

2026-10-28。目的：从文献里分出哪些做法**只依赖方程本身**（可以用、能讲清楚为什么有效），哪些是靠**强先验把问题变窄**（例如人为规定激波位置或跳跃条件，那就不如直接解析求解）。最终目标是参数化 PINN：楔角 θ ∈ [5°, 20°]、Ma 5，一次训练覆盖整个范围。

## 1. 理论：为什么普通 PINN 抓不住激波

1. **强形式残差对间断解没有意义。** Euler 方程的微分形式在激波处不成立，物理解是积分（弱）形式意义下的解，并且要再加熵条件才唯一。Chaumet & Giesselmann（2024）指出，PINN 的 L2 残差损失并不会随着激波近似变好而下降，所以“损失最小”不等于“解最准”，应该用弱（对偶）范数或者加粘性。De Ryck、Mishra 等的 wPINN（SIAM J. Numer. Anal. 2024）给出了弱形式 + 熵条件下的误差界。
2. **光滑网络倾向于等熵解。** 微分形式的 Euler 方程沿流线保持熵不变，网络会去找一个“光滑转折”的等熵解；滑移壁面边界还会造成很强的局部极小（TU Delft 关于高可压缩流 PINN 的学位论文）。
3. **两条有理论支撑的出路：**
   - **粘性消失法**：解 Euler + ν∇²U，再让 ν → 0。对标量守恒律，这样得到的极限就是熵解，是“物理解”的经典定义。守恒型粘性项下，任何光滑的粘性激波剖面积分后都自动满足 RH 跳跃条件，**不需要人为加 RH**。
   - **弱形式**：直接最小化守恒律积分形式的残差（对检验函数或控制体积分），再加熵条件。

**和我们实验的对应：** 15° 两阶段训练中，损失越降、解越漂向错误的激波角。这正是第 1 条说的现象：残差降权 d 把激波处的方程约束放掉了，那里的跳跃就可以不守恒。粘性消失法要求方程在激波内部也成立。

## 2. 方法分类

### A. 只依赖方程、有多维 Euler 证据的做法（可以用）

| 方法 | 做法 | 证据（最接近我们问题的） | 局限 |
|---|---|---|---|
| **自适应人工粘性 + 粘性递减**（Wassing, Langer, Bekemeyer, DLR；Comput. Fluids 2024，arXiv 2307.14045） | 守恒形式 Euler + ν·(a+\|q\|)·ΔW；ν 由网络在每点输出，罚项 \|ν − ν̃\| 把它拉向全局值 ν̃；ν̃ 从 7.5e-4 按幂律降到 0。三阶段：Adam 定粘性 → Adam 降粘性 → L-BFGS（ν̃=0）。配点用 Halton 均匀分布，不自适应 | **楔面斜激波，θ=10°，Ma ∈ (2,3) 作为网络输入（参数化）**：密度、Mach 数、Cp 相对误差约 0.5–0.7%，激波角误差 < 1° | 只做了一个楔角、弱激波（Ma ≤ 3）；作者说没有粘性时收敛不到物理解，只加熵正则也不够 |
| **激波探测器引导的自适应粘性**（力学学报 2025，doi 10.6052/0459-1879-25-434） | 用连续的激波指示函数（来自网络自己的解）决定在哪里加粘性，光滑区罚粘性；Mach 分层的自适应重采样；四阶段渐进训练 | **单楔，Ma 2–3 参数化：激波角误差 < 0.2°**；三楔进气道：场量平均绝对误差 < 1%，激波角误差 < 0.3° | 摘要未说明楔角是否作为输入 |
| **局部人工粘性（标量 / 矩阵）**（Wassing 等，Phys. Fluids 2025，arXiv 2408.17364） | 压力梯度传感器决定粘性作用区（传感器 detach），ν 全局常数网格搜索得到 | 跨声速翼型，Cp 误差 0.3–0.4%；攻角参数化 0.12–0.44% | 强一些的激波位置不准；不加粘性就捕捉不到激波 |
| **PINNs-WE 残差降权**（Liu 等，arXiv 2206.03864） | 残差除以 1 + α(\|∇·u\| − ∇·u)，让训练集中在光滑区 | 一维 / 二维 Riemann 问题，和 WENO-Z 比较 | 理论上放松了激波处约束，不保证 RH；**我们的 d 就是这个**。在 15° 强激波上正好暴露了这个问题 |
| **弱形式 / wPINN**（De Ryck 等 2024；Chaumet & Giesselmann 2024） | 积分形式残差（检验函数或控制体）+ 熵条件 | 理论最完整；主要是标量和一维算例，Chaumet 推广到方程组 | 计算量大；多维 Euler 证据少 |
| **伪时间推进**（arXiv 2607.08130，2026） | 把定常问题改写成非定常 Euler，向定常推进 | 翼型多个工况 + 攻角 / Mach 参数化，无标注数据，称精度高、时间降到 1/7 | 只看到摘要 |
| **自适应激活函数**（Jagtap 等） | 可训练的激活斜率 | 超声速反问题中误差降约 5 倍 | 对正问题帮助有限；与 L-BFGS 配合不稳定（Wassing 和我们都遇到过） |
| **残差自适应采样**（RAD / RAR-D，Wu 等 2023） | 按残差加点 | 基准评测：单独使用解决不了激波前沿 | 只能辅助 |

### B. 靠强先验或额外数据的做法（应避免，或只作对照）

| 方法 | 先验是什么 |
|---|---|
| **激波装配 + RH 条件**（我们的第 3 步 `refine.py`；各种 cusp-capturing、level-set 分区网络） | 规定“这里有一道激波，两侧满足 RH”，等价于把解析结构告诉网络 |
| **按激波位置划分子域**（XPINN / cPINN 在激波处分区） | 需要事先知道激波位置 |
| **在已知激波处加密配点**（Mao 等 2020） | 需要事先知道激波位置 |
| **按已知激波位置局部加粘性**（Coutinho 等 2023 的参数化局部粘性） | 需要激波位置 |
| **反问题 + 数据**（Jagtap 等 2022：密度梯度数据、总质量等） | 用了解的数据，不是正问题 |

### C. 我们现有配方里各项的定性

| 项 | 归类 | 说明 |
|---|---|---|
| 可学习局部粘性 ν = ν_min + s² | A | 与 Wassing 的自适应粘性同类 |
| 粘性逐步减小 | A | 粘性消失法，理论最清楚 |
| 残差降权 d | A，但有缺陷 | 放松激波处约束，强激波下跳跃不守恒（15° 的主要误差来源） |
| 方框积分守恒损失 | A（弱形式） | 理论上就是方程的积分形式，不含激波信息；但我们的版本只用了无粘通量 |
| 壁面附近压低粘性 | 弱先验 | 用到壁面位置（几何本身已知，但属于手工设计） |
| RAD 加点 | A（辅助） | 只用残差，不含激波位置 |
| Fluent 网格点作配点 | 无先验（网格均匀），但依赖 CFD | 换成均匀随机点后精度略降 |
| 激波装配精修（第 3 步） | **B** | 用了 RH 条件，属于强先验 |

## 3. 精度对照

| 工作 | 问题 | 指标 |
|---|---|---|
| Wassing 2024 | 楔 10°，Ma 2–3 参数化 | 场量相对误差 0.5–0.7%，激波角 < 1° |
| 力学学报 2025 | 单楔 Ma 2–3 参数化 | 激波角 < 0.2° |
| Jagtap 2022（反问题，有数据） | 斜激波 | ρ 相对 L2 0.5–3.5% |
| **我们，10° Ma 5（单角度）** | | ρ 1.0–1.7%、p 1.8–2.8%，激波角 0.03–0.25° |
| **我们，15° Ma 5（单角度）** | | ρ 9.5%、p 14%，激波角 0.6° |

注意：文献里的楔面问题都是 Ma 2–3、楔角 10°，压比约 2–2.5。我们的 Ma 5、15°，压比 4.8；20° 压比更高。**没有找到 Ma 5、多个楔角、高精度的已发表结果。** θ ∈ [5°, 20°]、Ma 5 的参数化，在激波强度上超出了已有文献。

## 4. 建议的技术路线（只用方程）

1. **主线：粘性消失法**，按 Wassing 2024 的三阶段方式，但针对强激波：
   - 守恒形式残差，粘性 ν·(a+\|q\|)·ΔU（按当地波速缩放，强激波自动得到更大的粘性）；
   - ν 由网络输出，罚项拉向全局 ν̃，ν̃ 逐步降到很小；
   - 激波处**不降权**，或只在早期降权、后期去掉，让方程在激波内部也成立，跳跃条件自然满足；
   - 均匀配点（Halton），可以叠加只用残差的自适应加点。
2. **参数化**：θ 作为网络输入，计算域用 (x, y, θ) 统一描述，配点在 θ ∈ [5°, 20°] 上均匀分布；用斜激波精确解评估每个角度。
3. **对照组**：现有带 d 降权的配方，以及加不加弱形式积分损失。
4. 激波装配精修（第 3 步）不再作为主要结果，只作为“如果允许 RH 先验，精度上限是多少”的对照。
